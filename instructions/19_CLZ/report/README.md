# CLZ 報告資料

## 1. 演算法設計說明

本組的 CLZ（Count Leading Zeros）函式計算 32-bit 無號整數從最高位元開始
連續出現的 0 數量。演算法採用二分搜尋法，將可能的前導零區段逐步縮小：

1. 先檢查輸入值的前 16 位元是否全部為 0。若是，計數器加 16，並將輸入左移 16 位。
2. 再檢查目前輸入的前 8 位元是否全部為 0。若是，計數器加 8，並將輸入左移 8 位。
3. 接著檢查前 4 位元，必要時計數器加 4 並左移 4 位。
4. 再檢查前 2 位元，必要時計數器加 2 並左移 2 位。
5. 最後檢查最高位元是否為 0，若是則計數器加 1。

如果輸入為 `0x00000000`，函式直接回傳 `32`。這個特殊處理符合 CLZ
規格，也避免全零輸入在分段檢查後得到錯誤結果。整個流程最多執行五次區段
檢查，時間複雜度為 `O(1)`。

## 2. 測試案例與結果

測試程式以 10 組測資驗證不同的前導零數量，包含最高位元為 1、最低位元為 1
以及全零輸入等邊界案例。

| 測試 | 輸入 | 預期結果 |
|---:|---|---:|
| 1 | `0x80000000` | `CLZ = 0` |
| 2 | `0x40000000` | `CLZ = 1` |
| 3 | `0x20000000` | `CLZ = 2` |
| 4 | `0x10000000` | `CLZ = 3` |
| 5 | `0x08000000` | `CLZ = 4` |
| 6 | `0x01000000` | `CLZ = 7` |
| 7 | `0x00100000` | `CLZ = 11` |
| 8 | `0x00010000` | `CLZ = 15` |
| 9 | `0x00000001` | `CLZ = 31` |
| 10 | `0x00000000` | `CLZ = 32` |

### 終端機輸出

```text
Test  1: CLZ(0x80000000) = 0
Test  2: CLZ(0x40000000) = 1
Test  3: CLZ(0x20000000) = 2
Test  4: CLZ(0x10000000) = 3
Test  5: CLZ(0x08000000) = 4
Test  6: CLZ(0x01000000) = 7
Test  7: CLZ(0x00100000) = 11
Test  8: CLZ(0x00010000) = 15
Test  9: CLZ(0x00000001) = 31
Test 10: CLZ(0x00000000) = 32
```

測試結果與 CLZ 規格一致。第 9 組確認只有最低位元為 1 時會得到 31，
第 10 組確認全零輸入依規格得到 32。
